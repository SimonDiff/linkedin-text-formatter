# Contributing

Thanks for helping out.

- **Bugs and feature requests:** open a [GitHub issue](https://github.com/SimonDiff/linkedin-text-formatter/issues)
  or DM me on [LinkedIn](https://www.linkedin.com/in/simondiff/). For bugs, say where it happened (post, comment or message),
  which Chrome version you use, and add a screenshot if you can.
- **Pull requests:** welcome. Keep them small and focused, run `node --test tests/*.test.js` before opening one,
  and test the change on linkedin.com in posts, comments and messages.
- **Other writing systems:** if you want to support a non-Latin script, a fork is often the better home for it.
  Start from `src/unicode.js`. Tell me about it and I'll link to it from the README.

By contributing you agree that your work is released under the [MIT License](LICENSE).
